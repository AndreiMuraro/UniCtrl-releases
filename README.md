# UniCtrl — versões

Aqui ficam só os executáveis publicados do **UniCtrl** (KVM por software: um mouse, um teclado e o fone passando entre Windows e Linux ao arrastar o cursor para a borda da tela).

Versão atual: **0.2.0**. Baixe (clique no arquivo e depois em *Download raw*):

- [`unictrl-windows.zip`](unictrl-windows.zip): Windows 10/11, sem precisar de administrador.
- [`unictrl-linux.tar.gz`](unictrl-linux.tar.gz): Linux X11 (testado no Linux Mint), sem root.

Depois de instalado, o UniCtrl se atualiza sozinho a partir daqui. Cada versão vem com um `manifest.json` assinado digitalmente; o app recusa qualquer arquivo que não tenha a assinatura certa.
