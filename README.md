# UniCtrl — versões

Aqui ficam só os executáveis publicados do **UniCtrl** (um mouse, um teclado e o fone passando entre os computadores ao arrastar o cursor para a borda da tela).

## Baixar

Clique no arquivo do seu sistema e depois no botão de download (seta para baixo, no canto direito):

- [`unictrl-windows.zip`](unictrl-windows.zip): Windows 10/11, sem precisar de administrador.
- [`unictrl-linux.tar.gz`](unictrl-linux.tar.gz): Linux X11 (testado no Linux Mint), sem root.
- [`unictrl-macos.zip`](unictrl-macos.zip): macOS (experimental, ainda não testado num Mac de verdade).

Estes arquivos são sempre a versão mais recente. A versão está no `manifest.json`.

Depois de instalado no Windows ou no Linux, o UniCtrl se atualiza sozinho a partir daqui. Cada versão vem com um `manifest.json` assinado digitalmente, e o app recusa qualquer arquivo sem a assinatura certa. No Mac, o painel apenas avisa quando há versão nova.
